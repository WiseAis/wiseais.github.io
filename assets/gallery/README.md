# Galeri görseli ekleme

Dört fotoğraf şimdilik GitHub Pages üzerinde `sameOriginHosted: true` ile sunulur. Çekim bilgileri yayın sürümünden kaldırılmıştır. Kart ve görüntüleyici yalnız fotoğraf adı, açıklama ve görseli gösterir.

Her kayıt `id`, `title`, `object`, `alt`, `description`, `previewUrl`, `fullUrl`, `sameOriginHosted` alanlarını kullanır. `previewUrl` küçük JPEG'e, `fullUrl` büyük JPEG'e gider. Büyük dosya yalnız kart açılınca istenir.

Dış barındırmaya geçerken iki URL'yi sağlayıcının HTTPS adresleriyle değiştir ve `sameOriginHosted` değerini `false` yap. Sayfada yükleme ekranı ya da sağlayıcı anahtarı bulunmaz.

Kaynak fotoğraflar korunmuştur; JPEG türevleri kırpılmamış ve EXIF içermeyen web kopyalarıdır. Önizlemeler 1400 px uzun kenarlı, yaklaşık 239–246 KB; büyük sürümler kaynak ölçülerindedir.
